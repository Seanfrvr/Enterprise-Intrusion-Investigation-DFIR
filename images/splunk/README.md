# Splunk Evidence Images

Store original screenshots from the author's own Splunk investigations here.

For each image:
- Use a descriptive filename, e.g. `hunt-01-powershell-processes.png`.
- Remove credentials, tokens, personal data and unrelated browser information.
- Include the search or saved-search name and the time range in the caption.
- Explain what the result demonstrates and what it does not establish.
- Link the image to the relevant report or evidence ID.

Do not use screenshots copied from unrelated projects or third-party dashboards as if they were your own work. Mark conceptual mock-ups clearly. Do not publish restricted training-room answers or walkthrough material.
