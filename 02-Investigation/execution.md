# Execution

> Documentation status: in development.

## Scope

Analysis of suspicious process execution and the use of native Windows administration utilities.

## Investigative approach

Correlate process creation, command-line telemetry, parent-child relationships, host identity, and timestamps. Assess whether activity is consistent with administrative use or an anomalous execution chain.

## Findings

To be populated from permitted evidence. Do not treat tool presence alone as proof of malicious activity.
